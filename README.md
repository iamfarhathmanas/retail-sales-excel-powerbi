# Retail Sales Performance — Excel & Power BI

An Excel and Power BI portfolio project for analyzing retail revenue, profit, product contribution, regional performance and sales channels.

## Tools
- Microsoft Excel
- Microsoft Power BI

## Excel Analysis
- Structured sales dataset
- KPI calculations
- Product-level revenue and profit analysis
- Dashboard planning sheet

## Power BI Dashboard
Recommended visuals:
- Total Revenue
- Total Profit
- Profit Margin
- Units Sold
- Monthly Revenue & Profit trend
- Revenue by Region
- Revenue by Product
- Profit Margin by Channel
- Slicers for Date, Region, Product and Channel

## Dataset Note
Generated practice data for portfolio demonstration; it is not employer/client data.

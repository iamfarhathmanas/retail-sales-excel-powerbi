# Excel Analysis

## KPI formulas
- Total Revenue: `=SUM(RetailSales[Revenue])`
- Total Profit: `=SUM(RetailSales[Profit])`
- Profit Margin: `=Total Profit/Total Revenue`
- Units Sold: `=SUM(RetailSales[Quantity])`
